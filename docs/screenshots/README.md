# Documentation screenshots

Captured from the installed development build at `416c68d`, using the native
GTK/libadwaita interface in dark mode.

- `overview.png`: connected controls with sample TV data supplied by the existing
  `tools/mock_bscpylgtvcommand.py` fixture (brightness 65, volume 20, unmuted).
- `tvs-empty.png`: TVs with an empty configuration.

The app ran with a temporary configuration in an isolated display session.
The screenshots contain no personal TV addresses or credentials.

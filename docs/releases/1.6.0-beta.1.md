# LG Buddy v1.6.0-beta.1

The first 1.6 beta brings brightness and sound controls, TV details, and native
pairing into the desktop app.

## What’s new

- **Overview:** Adjust OLED pixel brightness and TV volume with sliders, toggle
  mute, and see the primary TV with Connected, Connecting, or Disconnected
  status. Brightness, audio, and summary feedback load independently, with
  retry actions for failures.
- **TVs:** Move between Overview and TVs with adaptive navigation. Inspect the
  configured TV’s IP address, MAC address, managed HDMI input, control platform,
  local credential state, and optional model name. These details are read-only;
  a saved credential does not prove that the TV is reachable or authenticated.
- **Pair your first TV:** From the zero-TV state, use native webOS pairing with
  the TV’s IP address, MAC address, and HDMI input. The dialog shows connecting,
  TV confirmation, verification, and saving phases. Validation stays inline,
  failures include recovery guidance, pairing can be cancelled before saving,
  and success confirms the saved TV.

## Beta scope

This beta supports zero or one configured TV. GUI Settings, credential
health/repair, additional TV management, and GUI installation/service wiring
are not included yet. Use the release installer and `./configure.sh` for
installation and setup; the stable CLI remains available for headless controls
and settings.

## Requirements

Official bundles support the Ubuntu 24.04 runtime baseline: GTK 4.14,
libadwaita 1.5, and glibc 2.39 or newer. Enable TV On With Mobile / Wake-on-LAN
on the TV; a static IP and Always Ready are strongly recommended.
